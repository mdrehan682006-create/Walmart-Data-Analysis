Walmart Sales Analysis & Dashboard
Project Overview

This project presents an end-to-end retail analytics solution using Walmart weekly sales data.
Tools Used
Python (Pandas, NumPy, Matplotlib, Seaborn, SciPy)
PostgreSQL SQL
Power BI
Project Components

1. Exploratory Data Analysis (EDA)
Data quality assessment
Feature engineering
Sales distribution analysis
Store performance analysis
Holiday impact analysis
Correlation analysis
Time series analysis
Outlier detection
Statistical hypothesis testing

2. SQL Analysis
The SQL script contains:
Total Revenue KPI
Average Weekly Sales
Top/Bottom Stores
Store Contribution Analysis
Monthly & Quarterly Trends
Holiday vs Non-Holiday Analysis
Ranking Functions
Running Totals
Moving Averages
Month-over-Month Growth
Percentile Analysis
Outlier Detection

3. Power BI Dashboard
Dashboard includes:
Revenue KPIs
Sales Trend Analysis
Store Performance Rankings
Contribution Analysis
Holiday Impact Visualizations
Interactive Filters and Drilldowns
Key Insights
Dataset contains 45 stores and 6,435 weekly records.
Data is clean with no missing values or duplicates.
Significant variation exists between store performances.
Holiday weeks affect sales behavior.
Seasonal patterns are visible across the timeline.
